# 《问道长生》修仙模拟器 · HTML 交互版

将 [雾见川](https://github.com/MeteorNOX) 的《修仙模拟器 · 问道长生》设定文档（原为 AI 主持的 LaTeX 文字游戏）改编为可在浏览器中游玩的交互式网页游戏。

> 真实修仙界，会死，非龙傲天。——本作灵魂

## 技术栈

- **Vite + React + TypeScript**（Vite 8 / React 19 / TS 7 原生版）
- **Zustand**（全局状态 + localStorage 持久化）
- **Tailwind CSS v4 + 自研宣纸设计系统**（100% 复刻原文 LaTeX 配色体系与组件库）

## 架构

## 核心设计（与用户确认的设计决策）

- **混合引擎**：代码管全部数值结算（原文公式 100%），LLM 管叙事与自由行动判定
- **LLM 可配置**：设置页填 OpenAI 兼容端点（默认 DeepSeek `api.deepseek.com` / `deepseek-v4-flash`），Key 存浏览器 localStorage
- **时间为 AI 权威**：`timePassedMonths` 由 AI 返回——返回多少推进多少（钳制 0~12），未返回 / 返回 0 / 回合失败一律不流逝；代码不再做叙事时间解析（曾用正则折算「数日/半月/数月」但中文时间表述歧义太多，已废弃）。时间线只按整月推进，不足一月的余数跨回合累积（`flags.ageMonths`），保证「入道第几年」与年龄/寿元始终同步
- **剧情锚点接续**：每回合把上一回合叙事结尾注入 system（截 400 字），强制 AI 保持场所/人物/事件一致，防止剧情乱跳；LLM 历史窗口 24 条（最近 12 回合）
- **场景由代码决定**：背景只随系统指令切换（坊市=鎏金 / 修炼洞府=青玉 / 突破=玄紫…），自由行动忽略 AI 的 scene，背景不再乱跳
- **异常状态实时同步**：系统指令回合也应用 AI 的状态 deltas（仅伤势/异常/心境，防数值双加）；伤势中文名自动映射内部 id；`status` 支持数组或单个字符串、`[]` 清除
- **自由输入行动**：选项只是快捷方式，任何输入都在世界逻辑内响应
- **离线降级**：无 Key / 断网时系统指令仍可玩（代码结算），自由行动有基础兜底库
- **回合卡自检**：每张回合卡显示「⌛ 流逝 X 月 / 未流逝」与「【数值变化】」，时间与状态来源一目了然

## 全局功能（游玩体验保障）

- **现场恢复**：每回合自动持久化完整现场（剧情流/当前选项/状态卡/场景），刷新浏览器直接无缝续玩，顶部短暂提示「已恢复 · 回合 #N」
- **放弃进度**：标题页提供「放弃进度 · 重新开始」入口（带确认）
- **清除本地数据**：设置页底部「⚠ 清除全部本地数据」按钮（二次确认）——一键删除设置/API Key/现场进度/全部存档/快照/余额缓存，之后刷新即全新状态；也可在浏览器控制台执行 `localStorage.clear()`
- **多标签防冲突**：另一标签页更新进度时，当前标签弹出「接管 / 忽略」提示（最后写入生效）
- **性能**：背景图提供压缩 WebP 副本（`npm run opt-bg` 生成，约 75MB → 3MB），游戏按 WebP → PNG → SVG 链加载；页面关闭前兜底保存现场
- 现场会话独立存储（`wdcd.session`），不占用 3 个手动存档槽位

## 存档 / 读档（v2）

- **手动存档含剧情流**：3 槽存档保存最近 50 回合剧情 + 当前选项 + 场景，读档后无缝续玩；槽位显示摘要（道号 · 境界 · 回合 · 时间）
- **防误操作**：覆盖确认、删除确认、读档覆盖当前进度确认、存/读成功提示
- **标题页读档**：标题页「读档（n/3 槽）」列出全部槽位详情供选择；「继续游戏」仍一键进最近进度
- **事件快照**：突破/渡劫/战斗前自动存快照（独立键，覆盖式）；失败/失利时弹出「回退到事件前重新决策」（前置不满足不误判）
- **死亡回档三级**：事件快照 → 现场会话 → 自动存档
- JSON 导出/导入保留（含剧情流），旧版存档自动兼容

## 时间系统（AI 权威 · 最终版）

- **唯一来源**：AI 返回的 `timePassedMonths`（0~12）——返回多少推进多少；未返回 / 0 / AI 失败 → 本回合不流逝
- **显式闭关**：`闭关 3 月` / `闭关 2 年` 的时长由代码解析（1~120 个月封顶），数值结算与其一致
- **跨回合累积**：小数月（AI 给 0.5 等）存入 `flags.ageMonths`，攒满 12 个月 = 1 年，年龄 +1、寿元 −1；时间线只按整月推进，年份/月份/年龄/寿元始终同步
- **寿元耗尽 = 坐化**：`lifespan ≤ 0` 触发坐化结局（死亡回档三级：事件快照 → 现场会话 → 自动存档）
- 曾尝试「叙事时间短语自动折算」（正则解析 数日/半月/数月/一年…），因中文时间表述歧义（时节 vs 时长、纪年 vs 流逝）反复出 bug，已整体废弃——时间完全交给 AI

## 异常状态（AI 同步 · 最终版）

- 伤势 `injury`：AI 用中文名（轻伤/重伤/垂死/内伤/中毒/心魔缠身）或 `null` 清除，自动映射内部 id；状态卡显示中文名
- 异常 `status`：字符串数组（`["中毒"]`）或单个字符串均可，`[]` 清除
- 心境 `mood`：0.5 / 1.0 / 1.2
- 系统指令回合：AI 的 deltas 以「状态模式」应用（只采纳伤势/异常/心境，数值字段跳过防止与代码结算双加）；自由行动回合全量应用（数值 + 状态）

## 余额查询（DeepSeek）

- **设置页**：「查询余额」按钮（在测试连接旁）——总余额 + 币种 + 可用状态 + 赠送/充值拆分，低余额（<¥10）红色预警
- **游戏内徽标**：标题页右上角 + 主界面工具栏常驻 `¥xx.xx`，点击展开详情；每 10 分钟自动刷新（localStorage 缓存，未过期不重复请求）
- 默认 DeepSeek 模板（`GET /user/balance`，按 baseUrl 识别）；其他服务商提示「无标准余额接口」
